## What ran

```bash

```

`module.msk`, `module.aurora`, `module.elasticache`, `module.eks`,
`module.iam_workloads`, `module.flink`, plus the kafka/rds/elasticache/eks
interface VPC endpoints.

groups + cluster, workload IAM roles, Flink, and VPC endpoints. It failed
on the Aurora cluster: `DBClusterSnapshotAlreadyExistsFault` — a
`rtdp-sandbox-final` snapshot existed from the previous teardown. Deleted
the stale snapshot (`aws rds delete-db-cluster-snapshot`), re-ran;
pass 2 destroyed the Aurora cluster, subnet group, and security group
(3 resources). A new `rtdp-sandbox-final` snapshot remains in the account.
