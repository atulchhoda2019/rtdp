### Code changes

- `internal/kafkax`: `authOpts()` — shared by transacter/reader/producer/admin clients.
- `internal/redisx`: TLS-aware client; adopted by feature-service, feature-materializer, orchestrator.
- `cmd/rtdp-topics`: in-cluster topic admin (replaces `docker compose exec kafka-topics.sh` — unreachable from outside the VPC).
- `FeaturesJob`: reads KDA runtime properties; applies SASL_SSL/AWS_MSK_IAM to source + both sinks.
- `tools/seed/seed.py`: `RTDP_SEED_AWS=1` mode — real S3, rtdp-topics, in-cluster DNS, no Flink REST submit, bundle sync to the bundles bucket.
- `tools/seed/Dockerfile` → `rtdp/tools` image (psql + seed + rtdp-topics; models trained at image build, deterministic seeds).

### Deploy layer

- `deploy/helm/rtdp-bootstrap`: SA `rtdp-bootstrap`, ESO `SecretStore` (no auth block → controller Pod Identity), `ExternalSecret rtdp-db` (DSN template — secret value never transits repo/transcript), PostSync Jobs `rtdp-migrate` (psql 001_init.sql) + `rtdp-seed`.
- `deploy/argocd/apps/`: all 10 services rewritten as multi-source apps (`$values` ref → `deploy/argocd/values/sandbox.yaml`, generated by `tools/aws/render-env.sh` from terraform outputs, committed). Added `ollama` (digest-pinned upstream image, initContainer pre-pulls `qwen2.5:0.5b` into shared emptyDir) and `rtdp-bootstrap`.
