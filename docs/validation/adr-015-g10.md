## Notable behavior

`pms.room.assign` with `preferred_floor=10` produced
`DECISION_PENDING_APPROVAL` with a held `ASSIGN_ROOM` intent — correct
per the hotel policy: floor 10 exceeds `auto_assign_floor=8`, so the
T1 action cannot complete alone; it waits for `role:front_desk_manager`
(ADR-014 machinery, reached through the gateway's `/v1/decide` route).
The `agent_call` row records outcome `PENDING_APPROVAL` with
`decision_id` linking to the decision fact:

```
pms.room.assign|PENDING_APPROVAL|91232c55-9cc3-4846-90c5-b509164d3f6f
```

## The no-bypass structural check (G10b)

`tests/e2e/test_agent_g10.py` statically inspects
`services/agent-gateway/*.go`: no `INSERT`/`UPDATE`/`DELETE`/`DROP`
against any table other than `agent_call`; the only HTTP targets are
the ingress, registry, and approval-service hosts; mutating dispatch
is exclusively `callDecide` -> `POST /v1/decide`. The gateway holds no
backend write credentials.

## Fixes landed en route

- `action_policies` id field is `action_policy_id` (not `policy_id` —
  contract-registry lookup key).
- Rules see flat `input["attr.X"]` (presence-guarded); policy
  conditions/selectors see nested `input.attr.X` — hotel ruleset
  rewritten to the convention.
- `ActionAutonomy.when`: new optional CEL selector — several gateway
  tools share an outcome; the selector picks the right intent and
  fails closed when unevaluable (`internal/bundle`,
  `services/orchestrator`).
- `POST /v1/grants` revokes prior live grants for the same
  principal->agent — one live grant per pair keeps minted links
  deterministically bound to a single grant id for revocation
  (`services/agent-registry`).
- `PRODUCTS` in `tools/seed/seed.py` gained `hotel_stay`.
